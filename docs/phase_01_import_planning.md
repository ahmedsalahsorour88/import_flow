# Phase 1: Import Planning & Feasibility (التخطيط ودراسة الجدوى للاستيراد)

## 📌 Overview
مرحلة التخطيط ودراسة الجدوى هي المرحلة الأولى في دورة حياة الاستيراد. تهدف هذه المرحلة إلى مراجعة المستندات الأولية (أوامر الشراء، الفواتير المبدئية، قوائم التعبئة)، احتساب حجوم وأوزان الشحنة (CBM & Chargeable Weight)، اختيار خطة واستراتيجية التحميل المناسبة، دراسة وسائل وسيناريوهات الشحن، الاستشارة الجمركية الأوليّة، وتقدير الرسوم الجمركية والضرائب المتوقعة.

---

## ⚙️ Business Processes Breakdown (العمليات التفصيلية)

### BP-001: Receive Purchase Order (استلام أو إدخال/تعديل أمر الشراء)
- **الغرض**: إنشاء أو تعديل أو استلام أمر الشراء المعتمد وربطه بالمشروع وشركة الاستيراد والمورد، وحساب إجمالي مبلغ الفاتورة/أمر الشراء (`Total PI/PO Amount`).
- **شاشة العرض والتعديل**: توفير زر "تعديل أمر الشراء" داخل شاشة عرض تفاصيل الأمر للتعديل الفوري المباشر على بنود الفاتورة المبدئية وقائمة التعبئة.
- **المدخلات**: بيانات أمر الشراء، المورد الأجنبي (MD-002)، الشركة المستوردة (MD-001)، المشروع (MD-007)، بنود الفاتورة (`Quantity` & `Unit Price`).
- **المخرجات**: سجل أمر الشراء المعتمد وإجمالي المبالغ (`Total PI/PO Amount`).

### BP-002: Review Proforma Invoice (مراجعة الفاتورة المبدئية PI)
- **الغرض**: تسجيل ومراجعة بيانات الفاتورة المبدئية المقدمة من المورد والتأكد من مطابقتها لأمر الشراء وشروط Incoterms والأسعار والمبالغ الإجمالية (`Total PI/PO Amount`).
- **التحقق**: تطابق العملة، شروط الدفع، فترة صلاحية العرض، ومطابقة البيانات المرجعية.

### BP-003: Review Packing List (مراجعة وتعديل قائمة التعبئة المبدئية)
- **الغرض**: إدخال ومراجعة وتعديل تفاصيل الطرود والكراتين والأبعاد والكتلة والوزن بنفس طريقة حاسبة الـ CBM التفاعلية.
- **البيانات والوحدات**:
  - بند التعريفة الجمركية `HS Code` لكل طرد/بند.
  - كود البند `Item Code`.
  - نوع التعبئة `Package Type` (Carton, Pallet, Bag, Wooden Crate, Drum, Container).
  - محول وحدات الأبعاد `Dimension Unit` (`cm`, `mm`, `m`).
  - أعداد القطع والطرود `Qty PCS` & `Qty PKG`.
  - الأبعاد القائمة (`Length`, `Width`, `Height`) حسب وحدة القياس المختارة.
  - أوزان الوحدة: الوزن الصافي `Net Wt/Unit (kg)` والوزن القائم `Gross Wt/Unit (kg)`.
- **الحسابات التلقائية الحية**:
  - إجمالي حجم الطرود CBM.
  - إجمالي الوزن الصافي والوزن القائم للشحنة.
  - الوزن الحجمي الخاضع للشحن الجوي (Air Chargeable Volumetric Weight).

### BP-004: Calculate Cargo Volume (CBM) & Chargeable Weight (حساب الحجم والوزن الخاضع للشحن)
- **الغرض**: احتساب إجمالي CBM للشحنة والوزن الحجمي (Volumetric Weight) والوزن الخاضع للشحن (Chargeable Weight) وفقًا لنوع الشحن (بحري / جوي / بري).
- **المعادلات التلقائية**:
  $$\text{CBM} = \frac{\text{Length (cm)} \times \text{Width (cm)} \times \text{Height (cm)}}{1,000,000} \times \text{Quantity}$$
  $$\text{Air Volumetric Weight (kg)} = \frac{\text{Volume (CBM)} \times 1,000}{6} \quad (\text{or } \text{CBM} \times 166.67)$$

### BP-005: Plan Cargo Loading (تخطيط تحميل الحاويات)
- **الغرض**: إعداد خطة التحميل للشحنات الفردية والمجمعة (FCL / LCL)، واختيار أعداد وأنواع الحاويات المناسبة (20ft, 40ft, 40HQ) باستخدام قواعد التحقق واستراتيجيات التحميل (MD-015).
- **التحقق**: عدم تجاوز الوزن الأقصى للحاوية (Max Payload) أو السعة الحجمية المتاحة.

### BP-006: Determine Shipping Method (تحديد وسيلة الشحن)
- **الغرض**: اختيار وسيلة الشحن المثلى (بحري FCL/LCL، جوي، بري) بناءً على طبيعة البضاعة، الموعد المحدد للوصول (ETA Required)، والتكلفة المتوقعة.

### BP-007: Evaluate Shipping Scenarios (تقييم سيناريوهات الشحن)
- **الغرض**: مقارنة سيناريوهات الشحن المختلفة من حيث التكلفة، مدة الترانزيت (Transit Time)، ومستوى الخدمة، واختيار السيناريو الأفضل وإرشادات الإدارة.

### BP-008: Manage Freight Quotations (إدارة طلبات عروض أسعار الشحن RFQ)
- **الغرض**: إنشاء طلب عرض سعر شحن (RFQ) وإرساله لمزودي خدمة الشحن (MD-003)، مقارنة العروض المستلمة، واعتماد العرض الأفضل وتجميده.

### BP-009: Consult Customs Broker (الاستشارة الجمركية الأولية)
- **الغرض**: مراجعة بنود HS Code الخاصة بالشحنة مع المستخلص الجمركي والتأكد من المستندات والموافقات الاستيرادية المطلوبة (عرض ميزان، عرض هيئة صادرات وواردات، موافقة اتصالات، إلخ).

### BP-010: Estimate Customs Duties & Taxes (تقدير الرسوم والضرائب الجمركية)
- **الغرض**: حساب إجمالي الضرائب والرسوم الجمركية المتوقعة مبدئيًا بناءً على بند التعريفة الجمركية (HS Code - MD-008).
- **قاعدة أساسية**: كل **HS Code** له نسب ضرائب ورسوم مختلفة. لا يجوز افتراض نسبة ثابتة لأي بند.
- **بنود الحساب الجمركي المصري**:
  - ضريبة الوارد (Import Duty) — نسبة من القيمة الجمركية (CIF) حسب HS Code
  - ضريبة القيمة المضافة (VAT) — نسبة من الوعاء الضريبي حسب HS Code (ليست دائماً 14%)
  - ضريبة الجدول (Schedule Tax) — نسبة إضافية حسب بند التعريفة (إن وجدت)
  - رسم الوارد (Import Fee) — إن وجد
  - رسوم الخدمات الجمركية (Customs Service Fees)
  - رسوم أساسية (Basic Fees)
  - رسم التنمية (Development Fee) — إن وجد
- **تسلسل الحساب**:
  $$\text{CIF Base} = \text{FOB Value} + \text{Freight} + \text{Insurance}$$
  $$\text{Import Duty} = \text{CIF Base} \times \text{HS Code Duty Rate \%}$$
  $$\text{VAT Base} = \text{CIF Base} + \text{Import Duty} + \text{Freight} + \text{Other Applicable Fees}$$
  $$\text{VAT} = \text{VAT Base} \times \text{HS Code VAT Rate \%}$$
  $$\text{Total} = \text{Import Duty} + \text{VAT} + \text{Schedule Tax} + \text{Service Fees} + \text{Basic Fees} + \text{Development Fee}$$

### BP-011: Assess Import Requirements (تقييم متطلبات ومستندات الاستيراد)
- **الغرض**: حصر جميع الشهادات المتطلبة (شهادة المنشأ COO، شهادة الفحص، الفاتورة الموثقة، موافقات الجهات العرض) قبل البدء في السير في إجراءات الشحن الفعلية.
