# Phase 10: Import File Closure & Archiving (إغلاق الملف والأرشفة التاريخية)

## 📌 Overview
المرحلة العاشرة هي المرحلة الأخيرة في دورة حياة ملف الاستيراد. تشمل التقييم الشامل للعملية التشغيلية والمالية، التأكد من إغلاق وتسوية جميع الفواتير والمهام، تغيير حالة ملف الاستيراد إلى **Closed**، وأرشفة كافة المستندات والسجلات بشكل نهائي في النظام المرجعي.

---

## ⚙️ Business Processes Breakdown (العمليات التفصيلية)

### BP-040: Close Import File & Historical Archival (إغلاق ملف الاستيراد والأرشفة)
- **الغرض**: المراجعة الشاملة النهائية لملف الاستيراد وإغلاقه بشكل نهائي ومنع أي تعديل مستقبلي عليه إلا بصلاحيات استثنائية.
- **شروط ومتطلبات الإغلاق (Closure Checklist)**:
  - ✅ استلام جميع المستندات الأصلية وإكمال التبادل الإلكتروني (CargoX / Doc Exchange).
  - ✅ إتمام الإفراج الجمركي واستلام البضاعة بالكامل في المخازن مع تسوية الفروق.
  - ✅ تسوية جميع الفواتير المالية والمستخلصين وشركات الشحن وحساب Landed Cost النهائي.
  - ✅ إغلاق جميع المهام التلقائية واليدوية المرتبطة بالملف (System & Manual Tasks).
- **نتيجة العملية**:
  - تحويل حالة الملف إلى **Closed / Archived**.
  - تجميد تعديل البيانات (Read-Only State) وحفظ السجل التاريخي الكامل لجميع الأحداث للتفتيش الجمركي والتدقيق المحاسبي مستقبلاً.
