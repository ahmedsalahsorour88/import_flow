  1. **Root Cause Analysis:** In `purchase_orders_screen.dart`, all 6 locations matching PO items to packing list items used:
     ```dart
     po.packingListItems.firstWhere((pl) => (item.itemCode != null && pl.itemCode == item.itemCode) || (item.hsCode != null && pl.hsCode == item.hsCode))
     ```
     Because `|| pl.hsCode == item.hsCode` was evaluated when both items shared the same HS Code (`8415820010`), `firstWhere` halted at the first package (`pl[0]`), repeatedly returning row 1's package for row 2 and any subsequent items.
  2. **Multi-Pass Non-Duplication Matching Engine (`PoPackingMatcher`):**
     - **Pass 1:** Exact Item Code / SKU match with alphanumeric normalization (uppercase, stripped spaces/punctuation).
     - **Pass 2:** Cross-field match (PO item code vs PL model/description, PL code vs PO description).
     - **Pass 3:** Strict sequential 1-to-1 matching for unassigned items under the same HS Code without duplicate reuse of packages.
     - **Pass 4:** Multi-package aggregation (summing multiple packages belonging to a single machine/item) and fallback to PO item specs if unassigned.
  3. **Synchronized Reporting:** Centralized `buildPoHsSummaryMap` ensures UI Tab 1, Excel export, and PDF export always output identical, authentic totals ($40.017\text{ m}^3$, $2254\text{ kg}$ net, $2274\text{ kg}$ gross).
