# 📘 دليل التثبيت والتشغيل الميداني للموظفين (Clean Machine Deployment Guide)

> **نظام ImportFlow ERP — الإصدار v1.0.188 Production Release**
> دليل مسؤولي تقنية المعلومات (IT Administrators) لتنصيب وتشغيل البرنامج على أجهزة الموظفين في أقل من دقيقتين.

---

## 🎯 1. متطلبات التشغيل الأساسية (System Prerequisites)

قبل تثبيت البرنامج على جهاز الموظف، تأكد من توافر الآتي:

| المتطلب | الحد الأدنى | الموصى به | ملاحظات |
|---------|-------------|-----------|---------|
| **نظام التشغيل** | Windows 10 (64-bit) | Windows 11 (64-bit) | الإصدارات 32-bit غير مدعومة |
| **المعالج (CPU)** | Intel Core i3 / AMD Ryzen 3 | Intel Core i5 / AMD Ryzen 5 فما فوق | ثنائي النواة كحد أدنى |
| **الذاكرة العشوائية (RAM)** | 4 جيجابايت | 8 جيجابايت فما فوق | |
| **مساحة القرص** | 1 جيجابايت مساحة فارغة | 5 جيجابايت مساحة فارغة | |
| **حزم مايكروسوفت** | Visual C++ Redistributable 2015-2022 (x64) | مثبتة افتراضياً في معظم أجهزة ويندوز الحديثة |

---

## ⚡ 2. أداة الفحص الذاتي السريع (Pre-Flight Diagnostics)

يمكن لمسؤول الـ IT تشغيل أداة الفحص التلقائي على جهاز الموظف قبل التثبيت:
```cmd
py -3.14 scripts/validate_clean_machine.py
```
سوف تقوم الأداة بفحص نظام التشغيل، ومكتبات Visual C++، وصلاحيات الكتابة، وتوافر المنفذ `28080` وإعطاء تقرير باللون الأخضر بتمام الجاهزية.

---

## 🚀 3. خطوات التثبيت (Installation Steps)

### الخيار 1: التثبيت السهل بنقرة واحدة عبر معالج التثبيت (Recommended)

1. انسخ ملف التثبيت:
   `Sorour_Logistics_Setup_v1.0.188.exe` إلى جهاز الموظف.
2. انقر نقراً مزدوجاً على الملف لفتح معالج التثبيت (Setup Wizard).
3. اختر مسار التثبيت (افتراضياً: `C:\Users\<User>\AppData\Local\Programs\Sorour Logistics` أو مجلد البرامج).
4. فعّل خيار **"إنشاء اختصار على سطح المكتب (Create Desktop Shortcut)"**.
5. اضغط **Install**. يستغرق التثبيت أقل من 30 ثانية.
6. عند اكتمال التثبيت، حدد **Launch Sorour Logistics** واضغط **Finish**.

> [!NOTE]
> لا يحتاج الجهاز إلى تثبيت لغة Python أو Flutter؛ البرنامج يأتي مدمجاً بكامل محركاته ومكتباته تلقائياً (Self-Contained Standalone).

---

## 🔐 4. أول تسجيل دخول وتغيير كلمة المرور (First Login)

1. تفتح شاشة تسجيل الدخول الأنيقة.
2. بيانات المدير الافتراضية للنظام:
   - **اسم المستخدم:** `admin`
   - **كلمة المرور الأولية:** تُحدد بواسطة متغير البيئة `ADMIN_INITIAL_PASSWORD` في ملف `.env` (أو يتم توليدها عشوائياً وتخزينها بأمان في `.env` عند أول تشغيل).
3. يُنصح بالدخول فوراً إلى **إدارة المستخدمين** وتغيير كلمة المرور وتكويد حسابات الموظفين وصلاحياتهم.

---

## 🌐 5. التثبيت في بيئة الشبكة المحلية متعددة الأجهزة (Multi-User Network Mode)

إذا كان السيرفر على جهاز مركزي وباقي الموظفين يتصلون به عبر الشبكة المحلية (LAN):

1. **على جهاز السيرفر الرئيسي:**
   - افتح المنفذ `28080` في جدار الحماية (Windows Firewall):
     ```cmd
     netsh advfirewall firewall add rule name="Sorour_Logistics_Server" dir=in action=allow protocol=TCP localport=28080
     ```
   - شغل خدمة الباك إند كخدمة خلفية دائمة:
     ```cmd
     py scripts/service_manager.py start
     py scripts/service_manager.py install-startup
     ```
2. **على أجهزة الموظفين (Clients):**
   - افتح تطبيق الفلاتر، وفي شاشة إعدادات الاتصال، أدخل عنوان IP الخاص بجهاز السيرفر (مثال: `http://192.168.1.100:28080`).

## 🛠️ 6. استكشاف الأخطاء وحلها (Troubleshooting)

### المشكلة 1: ظهور خطأ VCRUNTIME140.dll missing
* **السبب:** عدم تثبيت مكتبات Visual C++.
* **الحل:** قم بتحميل وتثبيت [Microsoft Visual C++ Redistributable 2015-2022 (x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe) وإعادة تشغيل الجهاز.

### المشكلة 2: رسالة "تعذر الاتصال بالسيرفر (Connection Refused)"
* **الحل:**
  1. تأكد من عمل السيرفر عبر: `py scripts/service_manager.py status`.
  2. تأكد من أن المنفذ `28080` غير محجوب بجدار الحماية أو برنامج الحماية (Antivirus).
  3. تأكد من أن السيرفر والعميل على نفس الشبكة المحلية وتستطيع عمل `ping` لعنوان السيرفر.
